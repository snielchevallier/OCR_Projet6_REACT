# Sportsee

## Prérequis

- Node.js (version 18 ou supérieure)
- npm

## Installation

```bash
# Installer les dépendances
npm install
```
## Configuration
- renommer le fichier .env.example en .env
- modifier la variable VITE_API_URL avec votre URL de l'api

## Démarrage

```bash
# Démarrer le serveur de développement
npm run dev
